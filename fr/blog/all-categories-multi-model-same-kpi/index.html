TOUTES CATÉGORIES · MULTIMODÈLE · MÊME KPI

Le principe SAME KPI signifie que, dans une même catégorie et une même version de taxonomie, chaque modèle est évalué avec le même signal, la même question et la même règle de verdict.

Registre canonique

Chaque catégorie possède sa liste versionnée. Avant l’audit, on fige registry_version, les définitions des signaux, les critères, la méthode, prompt_version et l’instantané des preuves.

Deux niveaux

La vérité déterministe vérifie directement l’existant : HTTP, HTML, données structurées, fichiers, liens, API et preuves techniques. L’observation multimodèle examine ce que chaque système d’IA trouve, comprend, omet ou cite.

Indépendance des observateurs

ChatGPT, Claude, Gemini et Perplexity sont exécutés séparément. Les réponses brutes sont conservées avant normalisation.

Métriques distinctes

Qualité du site, accord entre modèles, couverture des preuves et complétude d’une exécution constituent des dimensions différentes. SITE TRUTH → SIGNAL → SAME KPI → SAME TEST → 4 AI → 4 OBSERVATIONS → EVIDENCE → AGREEMENT / DISAGREEMENT → HISTORY.
