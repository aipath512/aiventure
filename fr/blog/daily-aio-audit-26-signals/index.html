AUDIT AIO QUOTIDIEN — 26 signaux, une méthode identique chaque jour

L’AIO devient mesurable lorsque les mêmes signaux sont vérifiés de manière répétable, avec la même méthode et des preuves conservées.

Protocole quotidien

Chacun des 26 signaux du registre AIO actif reçoit PASS / PARTIAL / FAIL / UNKNOWN / N/A. UNKNOWN n’est pas FAIL.

Vérification des ressources

HTTP 200 ne suffit pas : STATUS → CONTENT-TYPE → FINAL URL → TITLE → H1 → CANONICAL → EXPECTED CONTENT.

Site en ligne et dépôt

REPOSITORY ≠ DEPLOYED ≠ LIVE ≠ VERIFIED.

Remédiation

PROBLEM → WHERE → ACTION → VERIFY. Une exécution peut utiliser l’identifiant AIO-RUN-YYYYMMDD-HHMM. La conservation des résultats permet les comparaisons T1→T2 et la détection des régressions.
