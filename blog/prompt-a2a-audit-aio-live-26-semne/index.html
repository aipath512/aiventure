Prompt A2A pentru audit AIO live: 26 de semnale, dovezi și scor reproducibil

Un audit AIO util este live, repetabil și bazat pe dovezi. Nu este suficient să existe fișiere pentru AI; ele trebuie să descrie corect paginile publicate.

Ce verifică

Agentul verifică homepage-ul, pagina AIO, llms.txt, robots.txt, sitemap.xml și artefactele declarate: acces HTTP, format, headinguri, ancore, rezumate, sesiuni, date și concordanța cu paginile live.

Scor și verdict

PASS valorează un punct. PARTIAL și FAIL valorează zero. UNKNOWN este raportat separat. Scorul confirmat este PASS/26 × 100.

Dovezi și comparație

Fiecare semnal include regulă, observație, URL, evidence ID și motiv. BEFORE și AFTER se compară numai cu aceeași metodă și dovezi păstrate; altfel, delta este necalculabilă.

Concluzie

Promptul transformă auditul AIO dintr-un scor declarativ într-un proces verificabil, cu timestamp, coduri HTTP, hash SHA-256, limite și priorități de corectare.
