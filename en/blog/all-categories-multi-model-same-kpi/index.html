ART-000004 · AI-LENS · Multi-Model Signal Intelligence

ALL CATEGORIES · MULTI-MODEL · SAME KPI

SAME KPI means that, within the same category and taxonomy version, every model is assessed using the same signal, the same question and the same verdict rule.

Canonical registry

Each category has its own versioned list. Before an audit, the registry_version, signal definitions, criteria, method, prompt_version and evidence snapshot are frozen.

Two layers

Deterministic truth directly checks what exists: HTTP, HTML, structured data, files, links, APIs and technical evidence. Multi-model observation examines what each AI system finds, understands, omits or cites.

Observer independence

ChatGPT, Claude, Gemini and Perplexity run separately. Their raw responses are preserved before normalization.

Separate metrics

Site quality, model agreement, evidence coverage and run completeness are distinct dimensions. SITE TRUTH → SIGNAL → SAME KPI → SAME TEST → 4 AI → 4 OBSERVATIONS → EVIDENCE → AGREEMENT / DISAGREEMENT → HISTORY.
